# Agentic Location Web Intelligence System

An agentic research system that investigates public information about a place to answer a
natural-language question about it (e.g. "Would Harvard Square, Cambridge, MA be a good place
for a college student?") — producing a transparent, evidence-backed, cited assessment rather
than a generic recommendation. The map/UI is a demonstration environment for the agent; the
agent itself is the project.

Status: Milestone 1 complete — a deterministic, fixture-backed `LocationResearchAgent`
pipeline (planning, retrieval, evidence linking, verification, synthesis) with no external API
key required. See [`backend/README.md`](backend/README.md) to run it and
[`docs/architecture.md`](docs/architecture.md) for the design.
